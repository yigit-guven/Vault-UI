## [1.0.0-beta7.1] - 2026-04-28

### Changed
- Count Formatting: Items exceeding 9.9k (10,000+) now stop showing decimals (e.g., '10k' instead of '10.1k') for cleaner slot rendering.
- Dynamic Count Scaling: Items exceeding 99.9k (100,000+) now use a smaller font scale to ensure the count text fits perfectly within the item slot.
