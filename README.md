# Vault UI

A NeoForge mod providing a custom user interface for Vaults.

## Features

- Custom UI for Vault interactions.

## Setup

1. Import the project into your preferred IDE (IntelliJ IDEA is recommended).
2. Run the `genIntellijRuns` gradle task to generate run configurations.
3. Use the `runClient` configuration to start the game.
